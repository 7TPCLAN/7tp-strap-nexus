# 7TP Nexus Strap

**PLAY. CREATE. OPTIMIZE.**  
By 7TPCLAN — Developer: ThunderPainYT

7TP Nexus Strap is a Windows-first desktop utility built with Python and PySide6. This initial foundation includes the dark purple/black interface, dashboard, and navigation between planned modules.

## Current status
- Foundation desktop UI
- Dashboard and pages for Nexus Boost, Capture, Packs, Skies, and Profiles
- Planned features are clearly identified as placeholders
- No system settings are changed by this starter build

## Run locally
1. Install Python 3.10 or newer.
2. Install dependencies: `python -m pip install -r requirements.txt`
3. Start the app: `python src/main.py`

## Roadmap
- **Nexus Boost:** start with read-only system monitoring; make future optimizations transparent and reversible.
- **Nexus Capture:** select a recording backend before implementing capture.
- **Nexus Packs:** organize compatible packs with backups and restore support.
- **Nexus Skies:** manage supported presets/assets with clear compatibility limits.
- **Nexus Profiles:** save app preferences and named configurations.

Compatibility varies by game and platform. Nexus Strap will not bypass anti-cheat or promise unsupported game-file modifications.
